# تطبيق مساعدتي ريم 👧🇸🇾

تطبيق ذكاء اصطناعي تفاعلي لشخصية "ريم"، فتاة سورية عمرها 20 سنة تتحدث باللهجة السورية العفوية مع خاصية نطق الردود صوتياً.

## طريقة التشغيل:
1. انقر مرتين على ملف `run.bat` (في حال استخدام ويندوز).
2. أو افتح Terminal واكتب:
   pip install -r requirements.txt
   streamlit run app.py
3. أدخل مفتاح Gemini API المجاني الخاص بك في الشريط الجانبي واستمتع بالمحادثة!
